Open Coupons tries the known coupon codes on a checkout page and keeps the code giving the lowest total. The extension downloads the whole code database and looks a store up in the browser, and it collects no personal, browsing, or ad data. Anyone can search the database with no login and no ads. Source code is at [github.com/bryceaspringfield/open-coupons](https://github.com/bryceaspringfield/open-coupons).

Open the code database: [bryceaspringfield.github.io/open-coupons](https://bryceaspringfield.github.io/open-coupons/).
