importance: 1
category: add-ons
---

Open Coupons tries the known coupon codes on a checkout page and keeps the code giving the lowest total. The add-on downloads the whole code database and looks a store up in the browser, and it collects no personal, browsing, or ad data. Anyone can search the database with no login and no ads.

Open the code database at [bryceaspringfield.github.io/open-coupons](https://bryceaspringfield.github.io/open-coupons/).
