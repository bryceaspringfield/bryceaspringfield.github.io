The Price Error Finder reads public deal forums, fare trackers, and price-history sites every hour, scores each item by the size of the discount and the chance the seller honors the price, and lists the strongest candidates. Source code is at [github.com/bryceaspringfield/price-error-finder](https://github.com/bryceaspringfield/price-error-finder).
