# bryceaspringfield.github.io

Personal academic website of Bryce A. Springfield, built with Jekyll and the [al-folio](https://github.com/alshedivat/al-folio) theme (MIT license, `LICENSE`).

- Pages: `_pages/` (about, publications, projects, CV, news).
- CV data: `_data/cv.yml`. Publications: `_bibliography/papers.bib`. News items: `_news/`. Projects: `_projects/`.
- The `Deploy site` GitHub Action builds the site on every push to `main` and publishes it to the `gh-pages` branch.
